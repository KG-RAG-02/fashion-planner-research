# 0005. 집계만 내보내고, H&M 연구와 LLM 전송은 명시적으로 켜야 한다

- 상태: 채택
- 범위: H&M 자료원, 타깃 고객 가설, 응답 투영

## 맥락

H&M 데이터셋은 비상업 연구에만 쓸 수 있고 고객 단위 행을 담고 있습니다. 타깃 고객 가설은 리뷰 입력을 외부 모델 제공자에게 보냅니다. 둘 다 기술적 기본값이 아니라 배포자가 동의해야 하는 동작입니다.

## 결정

- 서비스는 집계만 내보냅니다. 가격 통계와 연령대별 고유 고객 수입니다. 한 프로필의 연령대 중 하나라도 10명 미만이면 그 프로필의 인원, 분모, 타깃 연령대를 모두 숨깁니다.
- 고객 ID와 행은 쿼리 밖으로 나가지 않고, 스냅샷에도 모델 입력에도 들어가지 않습니다.
- H&M 연구는 `RESEARCH_HM_NONCOMMERCIAL_RESEARCH=true`일 때만 실행합니다.
- 가설은 `RESEARCH_TARGET_LLM_TRANSFER_AUTHORIZED=true`이고 API 키가 있을 때만 요청합니다.
- H&M에서 온 결과에는 `non_commercial_research_only`, `operational_eligible: false`를 붙입니다.

## 결과

- 아무것도 설정하지 않으면 리뷰는 오류 없이 `no_results`와 분명한 이유를 돌려줍니다.
- 이 기능을 쓰려는 배포는 설정에 그 의사를 적어야 합니다.

## 검토한 대안

- **둘 다 기본으로 켭니다**(원래 프로젝트의 설정). 공개본에서는 코드를 실행하는 것만으로 배포자 대신 동의한 셈이 되므로 택하지 않았습니다.
- **API 키가 있으면 동의한 것으로 봅니다.** 키는 자격 증명이지 데이터 전송에 대한 동의가 아니므로 택하지 않았습니다.
